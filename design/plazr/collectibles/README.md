# Plazr collectibles

Twelve original inanimate badges: opal, crescent, snowflake, cursor, lantern,
violet crystal, letter W, orbit, lightning, flame, moonstone and compass.
No faces, people, animals, body parts or creatures.

Each SVG is an editable original. Each transparent 256px PNG is independent:
one product, one asset, one existing inventory ID. The steward compass retains
its moderator-only entitlement and is not a paid item.

Run `python design/plazr/collectibles/export_assets.py` from the repository root
with Inkscape installed. This exports the PNGs and catalog artwork metadata.
The compatibility atlas is regenerated from these same originals for old
clients. Current web and Flutter clients map historical URLs to independent
PNGs, including messages saved before the refresh. The removed ninth badge
remains unavailable.

References inform color, clarity and presentation; no reference screenshots or
third-party product pixels are distributed. Visual similarity has no numerical
certification. Product names, inventory IDs, prices and moderator rules are
handled separately by the server.
