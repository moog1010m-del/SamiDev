# إصلاح V5 — ظهور الأفاتار للطرف الآخر + إنهاء المباراة عند الخروج

## الأفاتار
- أصلحت مسار `/api/avatar/{user_id}` لكي يعمل للاعب الآخر حتى إذا دخل اللعبة بتذكرة لعبة بدون جلسة HTTP فعالة.
- المسار يعيد بايتات الصورة فقط ولا يعيد بيانات الحساب.
- معرف المستخدم عشوائي/opaque، وتمت إضافة rate-limit والتحقق من صيغة المعرّف و`Cross-Origin-Resource-Policy: same-origin`.
- فشل تحميل مؤقت لم يعد يُخزن كـ `null` لبقية المباراة؛ يمكن إعادة المحاولة عند تحديث roster.

## الخروج
- زر الخروج من قائمة الثلاث نقاط لا يفصل الاتصال مباشرة بعد بدء المباراة.
- يرسل أولًا حركة الاستسلام الأصلية `m:4` عبر GameLogic، وينتظر إقرار السيرفر، ثم ينفذ `leave_room`.
- إذا فشل تسجيل الاستسلام، لا يغادر بصمت ولا يمنح حالة disconnect فقط؛ تبقى المباراة مفتوحة ويظهر خطأ للمستخدم.
- زر EXIT السفلي يستخدم نفس نافذة الخروج الآمنة.
