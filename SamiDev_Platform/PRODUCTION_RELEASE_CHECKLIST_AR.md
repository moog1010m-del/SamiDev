# Checklist قبل إطلاق SamiDev العام

- [ ] ضع `SAMIDEV_ALLOWED_ORIGINS` على دومين اللعبة الحقيقي بدون `*`.
- [ ] ولّد `SAMIDEV_GAMEHOST_SERVICE_KEY` طويلًا وعشوائيًا.
- [ ] شغّل Redis + 3 Gateways + 3 GameHosts عبر Docker production stack.
- [ ] ضع TLS edge أمام `127.0.0.1:8088` وتأكد أن الرابط العام HTTPS/WSS.
- [ ] افتح اللعبة من المتصفح وأنشئ غرفة وتأكد أن الاسم المختار يظهر في القائمة والشات.
- [ ] جرّب دعوتين: الأولى يدخل بها الصديق، وإعادة استخدام نفس رابط الدعوة تُرفض.
- [ ] اختبر شات لاعبين على Gateway مختلفين وتأكد أن الرسالة تصل مرة واحدة.
- [ ] اختبر reconnect باستخدام player token بعد انقطاع الاتصال.
- [ ] اختبر أن اتصالًا جديدًا بنفس reconnect token يستبدل الاتصال القديم بشكل آمن.
- [ ] اختبر 1000 لاعب / 500 غرفة لمدة 30–60 دقيقة على Redis الحقيقي.
- [ ] نفذ reconnect storm بنسبة 10–20% أثناء الحمل.
- [ ] راقب Redis memory/latency، Gateway/GameHost CPU/RAM، وduplicate events.
- [ ] بعد إغلاق الاختبار تأكد من تنظيف الاتصالات والغرف وسجل الشات.
- [ ] تأكد أن Redis/GameHost غير مكشوفين للعامة، وأن `/metrics` داخلي فقط.
