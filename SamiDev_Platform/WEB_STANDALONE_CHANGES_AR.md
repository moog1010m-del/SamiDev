# SamiDev Web Standalone

هذه النسخة تعمل كتطبيق ويب مستقل بدون اعتماد على منصة هوية أو بوت خارجي.

## التغييرات

- اسم اللاعب يأتي من واجهة SamiDev عند إنشاء/دخول الغرفة.
- إعادة الاتصال تعتمد على `roomId` و`player token` المخزن في `sessionStorage`.
- الدعوات أصبحت روابط ويب مؤقتة أحادية الاستخدام بالشكل `?online=1&action=invite&invite=...`.
- زر دعوة صديق يستخدم Web Share API عند توفره، وإلا ينسخ الرابط.
- حُذفت متغيرات البيئة والأسرار الخاصة بالبوت والمصادقة الخارجية.
- بقيت GameHost authority وRedis/WebSocket والشات وإعادة الاتصال كما هي.

## ملاحظة أمان

`player token` أصبح اعتماد إعادة الاتصال الوحيد للمقعد، لذلك يجب اعتباره سرًا مؤقتًا وعدم وضعه في رابط مشاركة عام. الواجهة الحالية تحفظه في `sessionStorage` ولا تضيفه إلى رابط الدعوة.

إذا كان المنتج يحتاج حسابات دائمة أو اقتصادًا/إحصائيات مرتبطة بمستخدم محدد، أضف لاحقًا نظام مصادقة أولي مستقل عن طبقة المباراة.
