مسودة للمراجعة — ليست وثيقة إطلاق معتمدة

تصف هذه الصفحات الوظائف الحالية والفجوات المعلنة، ولا تُعد موافقة طفل أو ضمان امتثال.

  • الاسم القانوني للمالك أو الجهة المشغلة لم يُستكمل؛ Plazr اسم المشروع المعلن.
  • دولة التشغيل والقانون المنطبق لم يُحددا.
  • عنوان الدعم المحدد يحتاج تأكيد تفعيله واستقبال الرسائل.
  • مدد الاحتفاظ بسجلات الاستضافة والنسخ الاحتياطية ومواقع الاستضافة تحتاج توثيقًا فعليًا.
  • الجمهور يشمل دون 13 سنة، لكن موافقة ولي الأمر وحماية تجربة الأطفال غير مطبقتين في النسخة المراجعة.

تعامل باحترام

لا تستخدم الإهانات أو التهديد أو خطاب الكراهية أو التنمر أو الاستهداف المتكرر. لا تنتحل هوية لاعب أو مشرف ولا تطلب كلمات المرور أو رموز الدخول.

احمِ الخصوصية والمستخدمين الصغار

لا تنشر اسمًا حقيقيًا أو رقم هاتف أو عنوانًا أو صورة خاصة لغيرك دون حق. يُمنع المحتوى الجنسي والاستغلال والتحرش وطلب صور خاصة أو محاولة استدراج الأطفال أو نقلهم لاتصالات غير آمنة.

تتطلب المنصة التي تشمل الأطفال إجراءات إضافية تتجاوز هذه القواعد النصية. النسخة الحالية لم تستكمل مسار موافقة ولي الأمر أو تجربة أطفال منفصلة؛ راجع صفحة الأطفال قبل اعتماد الإطلاق.

العب بنزاهة

يُمنع الغش واستغلال الثغرات والتلاعب بالحركات أو المكافآت أو انتحال الأدوار الإدارية، وإغراق المحادثات أو تعمد تعطيل الطاولات والخدمات. أسماء الدول للمساحات لا تمنح أي عضو سلطة على غيره.

بلّغ بدل التصعيد

استخدم الإبلاغ في ملف اللاعب، أو support@plazr.cc بعد تفعيله. يتخذ المشرفون إجراءات ضمن صلاحياتهم مثل الكتم والإخراج والحظر. يمكن مراسلة الدعم بشأن قرار، دون ضمان رد فوري أو مراقبة دائمة غير مجهزة.
