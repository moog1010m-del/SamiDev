# حماية نسخ الإصدار بطبقات

تُستخدم تلقائيًا عبر `SamiDev_Flutter/tool/build_play.py` و`tool/build_android.ps1 -Mode release`.

الطبقات: تصغير وتغيير الأسماء المحلية، تغيير الخصائص الداخلية المدققة، إعادة تسمية بمعامل عشوائي لكل إصدار، تقسيم النصوص ومصفوفة نصوص بترميز RC4 بنسبة 75%، تبديل فهارسها وترتيبها، تعبيرات رقمية، وتحويل محدود لمسار التحكم بنسبة 6%. الخرائط المصدرية غير منشورة. Flutter يضيف obfuscate للـDart، وAndroid يستخدم R8 وتقليص الموارد.

هذه وسائل إعاقة للتحليل وليست ضمان تشفير سري: مفكك النصوص يحتاج وجوده داخل JavaScript عند التشغيل، وواجهات WebView وأسماء الانعكاس اللازمة محفوظة. لا تستخدم debug protection أو anti-debug أو dead-code injection، لتجنب إيقاف متصفحات المستخدمين أو تضخيم المحركات.

الأصل داخل game لا يتغير. الناتج المنفصل build/protected-game وتقرير الحماية بجانبه. احتفظ بمعامل الإصدار وملفات split-debug-info بشكل خاص؛ لا تُنسخ داخل Assets. يستطيع --protection-seed إعادة بناء الإصدار نفسه.

فحص Gradle يرفض Release إن كانت الأصول غير محمية أو تغيّرت بصماتها. debug مسموح دون حماية. لبناء إصدار، استخدم مسار build_play ليجهز الأصول المحمية قبل Flutter؛ flutter build مباشرة على أصول debug سيفشل عمدًا.

يجب أن يخدم الخادم نفس شجرة التوزيع المحمية عبر SAMIDEV_GAME_DIR عند نشرها مع التطبيق، حتى تبقى فحوص تطابق المحركات صحيحة. لا تنشر شجرة مختلفة أو تعطّل فحص التطابق.
