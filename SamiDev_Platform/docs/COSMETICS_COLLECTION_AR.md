# مجموعة الهوية والشات

أصول ثابتة محلية أصلية: شظية البرق، جمرة، حجر الليل، أفق الزمرد، حديقة الليل، وادي الجمر، حديث الفيروز، همس الليل، دفء الجمر. صُممت كورقة أصول واحدة، ثم استُخرجت عناصرها إلى ملفات WebP مستقلة دون تعديل محركات الألعاب. لا فيديوهات أو إهداء أو عملة إضافية.

- شارات الاسم: 150 أو 200 كوينز؛ أغلفة الملف: 250؛ إطارات الشات: 200.
- الشراء يستخدم نفس المحفظة والسجل ومعاملة PostgreSQL الحالية. لا يُفعّل العنصر المدفوع قبل امتلاكه.
- خانتا `profile_banner` و`chat_bubble` تُحفظان ضمن تجهيزات الحساب. يتوافر الرجوع للتصميم الافتراضي مجانًا.
- إطار الرسالة يختاره الخادم من تجهيز الحساب، ويُحفظ مع الرسالة في شات المساحة وشات المباراة. تغيير التصميم لاحقًا لا يغيّر الرسائل القديمة. حقل يرسله العميل باسم `chatBubble` لا يحدد التصميم.
- العميل يقبل معرّفات التصاميم المحلية المعروفة فقط؛ لا تُستخدم رسائل اللاعبين أو عناوين خارجية كـ CSS أو مسارات صور.
- الشارات القديمة المدفوعة لا تُعرض لمن لا يملكها ولا تباع مجددًا، وتظل المقتنيات السابقة قابلة للتجهيز. الشارة الافتراضية تبقى مجانية.
- معاينة قبل الشراء، ثم تأكيد السعر والرصيد المتبقي؛ لا شراء بمجرد لمس بطاقة المنتج.

التحقق: `tests/cosmetic_store_regression.py` للملكية والمحفظة والتاريخ والاتصال القديم، و`tests/cosmetic_store_cluster.py` لاختبار PostgreSQL/Redis وخادمين وWebSocket ومتصفح Chromium حقيقي. الثاني يتطلب `SAMIDEV_TEST_DATABASE_URL` و`SAMIDEV_TEST_REDIS_URL` محليين، و`SAMIDEV_PLAYWRIGHT_MODULE` إذا لم تكن الحزمة مثبتة ضمن Node المحلي.

تُنسخ الأصول المشتركة إلى حزمة فلاتر. أضيف دعم الأغلفة وإطار الرسائل إلى واجهتي الملف والشات الأصليتين؛ بناء تطبيق الهاتف وفحصه على جهاز فعلي غير مشمول باختبارات Chromium.
