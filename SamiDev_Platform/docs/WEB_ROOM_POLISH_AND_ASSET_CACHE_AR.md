# واجهة المساحة وتخزين الألعاب

- الغلاف الافتراضي أسود في الملف العام والخاص ومعاينة المتجر؛ الأغطية المجهزة تبقى كما هي.
- الخروج وإنشاء الطاولة زران متجاوران 44×44، والخروج أحمر هادئ.
- حقل الرسائل بخط 16px، يتمدد حتى نحو أربعة أسطر، مع إخفاء شريط التمرير؛ يعود لحجمه بعد الإرسال. ضبط viewport يمنع التكبير حيث يسمح المتصفح بذلك؛ بعض أنظمة الهواتف تتجاوز منع التكبير لأسباب تتعلق بإمكانية الوصول.
- الملصقات المملوكة تظهر في نافذة صغيرة بجوار الزر على الكمبيوتر، ومكان الرسائل على الهاتف، بلا backdrop أو showModal. تبقى الرسائل في DOM وتعود عند الإغلاق.

## التحميل بالخلفية

`tools/build_asset_cache.py` يولد `asset-worker.js` من ملفات الألعاب الفعلية، مع SHA-256 لكل ملف. العامل يخزن ملفات عامة محددة فقط، ويتحقق من بصمتها قبل التخزين. طلبات API والجلسات والصور الشخصية المتغيرة وclient-config وHTML خارج العقد. ملفات اللعبة تطلب بالشكل المعتاد؛ لا تغيير لبروتوكول اللعب أو فيزيائه.

يبدأ تنزيل الخلفية بعد تحميل الصفحة ووقت الخمول، باتصالين فقط، ويقدم آخر لعبة فتحها المستخدم. يتوقف تجهيز الخلفية أثناء اللعبة أو إخفاء الصفحة، ويتجنب التنزيل المسبق في وضع توفير البيانات أو اتصال 2G. إعادة الفتح تستعمل CacheStorage حتى مع no-store المرسل للملفات من السيرفر؛ لم نعطل تحقق سلامة محرك اللعبة. فشل التخزين/التحقق يعيد الطلب إلى مساره الشبكي المعتاد.

يتطلب HTTPS أو localhost. Flutter يستخدم الحزمة المحلية الموثقة ولا يسجل هذا العامل. يتغير اسم التخزين عند تغير الملفات وتزال نسخ التخزين القديمة عند تفعيل العامل الجديد. تحديث العامل ينتظر إغلاق التبويبات القديمة، ولا ينتزع التحكم أثناء مباراة. لا تخزن حسابات المستخدمين هنا، ولا تُحذف قواعد البيانات.

التحميل مرة لكل نسخة/متصفح/نطاق مع بقاء التخزين؛ تغيير نطاق trycloudflare يبدأ تخزينًا جديدًا. حذف بيانات المتصفح أو إخلاؤها بواسطة النظام يستدعي التنزيل مجددًا. هذا يختصر تنزيل الملفات المتكرر، ولا يلغي زمن فك الصور وتهيئة محرك الرسم.

## التحقق

- `tests/room_composer_browser.py`: متصفح فعلي، غلاف افتراضي/مجهز، الأزرار، تمدد الحقل، ملصقات الكمبيوتر/الهاتف، viewport، قراءة ملف مخزن دون شبكة واستثناء API.
- `tests/asset_cache_build.py`: تطابق البصمات، ثبات التوليد، وجود محركات الألعاب الأربع، غياب المسارات الخاصة.
- `tests/spa_game_host_browser.py`: انتظار داخل اللعبة، الانضمام، المشاهدة، الاستعادة والخروج؛ يحافظ على منصة SPA.

بعد أي تعديل: `tools/update_ui_build.py` ثم `tools/refresh_integrity.py` ثم `../SamiDev_Flutter/tool/sync_assets.py`.
