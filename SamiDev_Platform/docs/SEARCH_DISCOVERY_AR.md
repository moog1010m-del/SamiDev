# صفحات اكتشاف Plazr في محركات البحث

الاسم المنشور: Plazr / بلازر، مع ذكر بلايزر كصيغة بحث قريبة. المحتوى العام متاح بدون حساب أو JavaScript في `/discover/index.html`، مع صفحات أصلية للبلياردو والكيرم وكرة قدم الطاولة وكريزي 8، وصفحة لمن يبحث عن بديل بلاتو أو قيمزر وصفحة إنجليزية. لا نستخدم قوائم كلمات مخفية أو ادعاء التفوق على المنافسين، ولا ندّعي تقديم أونو نفسها.

المصدر: `tools/build_seo_pages.py`؛ يستدعيه بناء الواجهة تلقائيًا. يكتب ملفات UTF-8، عناوين وأوصافًا مستقلة، canonical، بطاقات مشاركة، بيانات WebPage المنظمة، `/robots.txt` و`/sitemap.xml`. جميع العناوين القانونية في هذا العمل تستخدم الدومين الذي طلبه المالك `https://plazr.cc`؛ يلزم التحقق من أنه الدومين النهائي المنشور قبل طلب الفهرسة. صفحات السياسة تبقى مسودات noindex كما هي، ولا تدخل خريطة الموقع.

بعد النشر:

1. تأكد أن الدومين وHTTPS يعملان وأن صفحات discover وrobots.txt وsitemap.xml ترجع 200 من الإنترنت، وأن الصفحة الرئيسية لا تحظر الزحف.
2. وحّد تحويل www وHTTP إلى الدومين النهائي على مستوى الاستضافة. إن تغيّر الدومين، عدّل ORIGIN في المولّد وروابط platform/index.html وأعد البناء.
3. أضف ملكية الدومين في Google Search Console وتحقق منها عبر DNS، ثم أرسل `https://plazr.cc/sitemap.xml`. لم تُنفّذ إضافة الملكية أو DNS من هذه البيئة.
4. افحص صفحة بلازر وصفحتي البلياردو والكيرم بأداة فحص الرابط، وراقب الفهرسة والاستعلامات والأداء على الهواتف قبل توسيع المحتوى.

لا يضمن إعداد SEO ظهورًا أو ترتيبًا محددًا. الروابط المكتسبة والمحتوى المفيد وسرعة النسخة المنشورة واستقرارها عوامل تحتاج متابعة. robots.txt توجيه للزواحف وليس بديلًا عن حماية API بصلاحيات الدخول.

التحقق: `tests/seo_pages.py` يستخدم HTTP مع المعالج الفعلي دون مصادقة، ويفحص الصفحات الثماني وخريطة الموقع والبيانات المنظمة وروابط المحتوى والأصول وتكرارية البناء. فحوص cache وbootstrap نجحت أيضًا.
