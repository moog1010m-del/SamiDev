# التحقيق في اشتباه الدخول لحساب آخر

تعامل مع البلاغ كاشتباه وصول غير مصرح إلى أن تُفحص الهوية والصلاحيات.
لا يكفي تطابق الاسم أو ظهور الصفحة الرئيسية للحكم باختراق الحساب.

## قبل إعادة تشغيل الخادم

- احتفظ بسجلات وقت المحاولة وإصدارات الخوادم (`git rev-parse HEAD` والتعديلات المحلية). لا تستبدل تعديلات الوكيل المحلية عميانيًا.
- من جلستين منفصلتين للحسابين، سجّل فقط حقول `id`, `username`, `role`, `isGuest` من `GET /api/me`.
- سجّل status و`error` لطلب `/api/auth/firebase`. لا تنسخ Request payload أو ID token أو Cookies.
- من حساب Google الثاني اختبر القراءة فقط لـ `GET /api/admin/users`: المتوقع 403 ADMIN_REQUIRED لغير الأدمن. لا تنفذ عمليات إدارة لاختبار الصلاحية.
- على الخادم افحص الربط: Firebase UID الموثق من SDK ↔ مفتاح ربط الهوية ↔ account ID ↔ firebaseUid/firebaseProject المخزنان ↔ role. قارن داخليًا بهوية الأدمن الأصلية وبقيمة bootstrap. لا تستخدم الاسم أو البريد كإثبات ملكية ولا تطبع ملفات الاعتماد.
- افحص مخزن الخادم وعدد النسخ وإعادة التشغيل. وضع memory يفقد الحسابات وحجز الأسماء عند إعادة التشغيل؛ ونسختان بذاكرتين منفصلتين لا تشتركان في سجل الهوية. لا تعِد التشغيل قبل حفظ الأدلة المتاحة.

## تفسير النتائج

- نفس account ID أو نجاح قراءة إدارة من حساب ثانٍ غير مخول: اشتباه فعلي بخلط الهوية/الصلاحية، يستدعي تقييد الوصول الخارجي وحفظ الأدلة قبل المعالجة وإلغاء الجلسات المتأثرة.
- اسم مطابق مع account ID مختلف وrole=user ورفض الإدارة: إعادة استخدام اسم أو انتحال اسم، وليس إثباتًا لفتح حساب الأدمن. افحص فقدان/اختلاف المخزن وتاريخ إنشاء الحسابين.
- رفض اليوزر الموجود: المتوقع 409 USERNAME_TAKEN دون إصدار جلسة لذلك الحساب. الدخول لهوية Google مرتبطة سابقًا يتجاهل الاسم المدخل ويعيد حساب تلك الهوية فقط.

## التعزيز المضاف

تطابق هوية Firebase ومشروعها يُفحص في مخزن الذاكرة، ويعاد فحصه عند إصدار الجلسة لجميع المخازن. أي عدم تطابق ينتج IDENTITY_CONFLICT دون إصدار جلسة جديدة.

السجل `samidev.auth` يخرج JSON للسجل القياسي للخادم: وقت المحاولة، معرف محاولة، معرف نسخة الخدمة، نوع المخزن، بصمة هوية غير قابلة للاستخدام للتوثيق، النتيجة، ومعرف الحساب ودوره عند النجاح. لا يسجل توكنات أو بريدًا أو كوكيز. احفظ سجلات الخادم في مكان وصوله مقيد؛ لا يوفر هذا استرجاعًا لأدلة سابقة لم تكن مسجلة.

الاختبارات المحلية تستخدم هويات مزود محاكية وHTTP حقيقي وPostgreSQL/Redis معزولين. لا تثبت بمفردها سبب البلاغ على خادم المستخدم أو تنشر التعديل عليه.
